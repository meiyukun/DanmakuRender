# 热点弹幕滚动展示

## 改动摘要

- 热点弹幕由固定居中展示改为从右向左滚动，减少对直播画面的持续遮挡。
- 热点与普通弹幕共用轨道和尾随碰撞逻辑；只要拉开安全距离，普通弹幕即可继续进入热点所在轨道，不再整段独占。
- 热点在途期间收到相同弹幕时，在当前位置刷新累计数量并继续移动，不跳回右侧，也不叠加同内容弹幕。
- 计数刷新会同步更新热点尾部宽度，普通弹幕按放大后热点的实际估算宽度保持安全间距。
- 滚动模式下默认不再省略长弹幕；热点前普通形态和热点正文都会保留完整内容。
- 单轮滚动锁定发射时的等级样式；完全离屏后再次出现时，才按最新累计数量重新选择等级。
- 热点在途期间不会触发会话超时，完全离屏后才开始计算 `session_timeout`。

## 新增配置

- `repeat_danmaku.hot_duration`：热点从右侧完全画外滚动到左侧完全画外的时长，默认8秒。

## 新增文件

- `tools/test_asswriter_hot_scroll.py`：热点原位刷新、普通弹幕尾随热点、会话超时，以及飞行中每次计数更新重启脉冲的测试。
- `tools/run_hotspot_stress_test.py`：使用真实视频生成多热点、多等级和高密度普通弹幕的压力测试片段；50/100级热点发射后会持续高频更新计数，并统计ASS脉冲片段。
- `docs/2026-07-17-hot-danmaku-scrolling.md`：本次功能变更记录。
