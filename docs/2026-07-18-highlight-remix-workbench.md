# 热点混剪编排面板优化

## 改动内容

- 自定义混剪支持填写最多 80 个字符的名称；该名称会保存到热点清单，并用于生成成片文件名。
- 热点素材进入编排面板后，Web 服务按需通过 FFmpeg 提取预览图，缓存于 `.temp/highlight-thumbnails/`，避免每次打开页面重复生成。
- 原有横向拼接条改为可折叠的响应式网格。素材较多时在面板内纵向滚动，不再依赖横向滚动条。
- 每张素材卡展示播放顺序、预览图、时长、热点类别、来源任务和来源场次，并支持拖动、前移、后移及移除。
- 自定义混剪版本列表优先显示用户填写的名称，同时保留内部版本 ID 便于识别。

## 新增或生成的文件

- 新增本变更日志：`docs/2026-07-18-highlight-remix-workbench.md`。
- 运行时按需生成缩略图缓存：`.temp/highlight-thumbnails/<内容摘要>.jpg`；该目录不是业务结果，可安全清理，之后会自动重新生成。
