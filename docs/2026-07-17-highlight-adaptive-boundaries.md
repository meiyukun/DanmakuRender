# 热点片段自适应边界优化

## 改动内容

- 使用高于局部基线的累计弹幕量分位点确定热点主体，减少低强度缓慢长尾进入成片。
- 新增弹幕反应延迟补偿，在检测到的主体起点之前保留更多画面铺垫。
- 相邻峰只有在曲线持续回到基线后才拆分，避免宽峰、次级增长被误判为多个热点。
- 超过最大片段时长时优先保留检测起点并裁剪尾部；只有峰值确实超出时长范围时才重新定位，同时保留较充足的峰前内容。
- 在分析结果中记录事件基线、主体起止点，便于后续从清单诊断边界效果。

## 新增配置

- `pre_roll_seconds`：热点主体前保留的总时间，同时补偿弹幕反应延迟和内容铺垫。
- `boundary_start_quantile`、`boundary_end_quantile`：热点主体在累计超额弹幕量中的起止分位点。
- `peak_merge_quiet_seconds`：峰间曲线需要持续接近基线的时间。
- `max_clip_peak_position_ratio`：超宽事件重新定位时，峰值在最大长度片段中的位置上限。
