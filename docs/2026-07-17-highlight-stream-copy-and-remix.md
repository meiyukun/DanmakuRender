# 热点无重编码剪辑与片段重混

- 热点任务默认以关键帧向外对齐的方式直接复制视频流；分段媒体参数不兼容时整场回退重新编码。
- 关键帧向外对齐导致单个小片段总共额外增加超过4秒时，自动只重新编码本次任务的热点小片段，避免长关键帧间隔把几十秒热点扩成数分钟；不会重新编码整场直播。
- 多个输出方案改为类别并集，只生成一份初始混剪，统一使用 `all` 的片段数和总时长限制。
- 所有审核通过的小片段持久保存到输出目录的 `clips/`，清单升级为 version 2，记录请求边界、实际关键帧边界和编码方式。
- 小片段严格对应单次独立热点事件；类别仅用于筛选和标注，不会先把同类事件合成类别视频。例如4个爆笑事件和3个疑惑事件会保存为7个小片段。
- Web 支持浏览已生成的片段、预览、排序、另存为新混剪版本，并为后续显式上传保留版本记录。
- 热点素材库采用响应式视频卡片和固定混剪工作台；支持整卡选择、类别筛选、全选/反选/清空、独立拖拽排序、删除确认、版本管理和操作通知。
- 素材库统一展示自动和手动热点场次，并在独立小片段前提供自动拼接成片预览；旧版自动清单可查看成片和删除场次，新版场次均可进行相同的片段重混操作。
