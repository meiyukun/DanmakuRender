# Web 手动热点剪辑

## 改动

- 直播整场结束时持久化场次与全部分段快照，不受后续流水线内存释放影响。
- 新增 Web“热点剪辑”页面，可选择已结束直播、调整分段、视频源、字幕策略、输出类别和高级 YAML 覆盖。
- 支持从录制任务输出目录扫描旧录像，根据时长、文件时间和下播等待时间生成候选场次。
- 手动任务每次使用独立运行 ID 和输出目录；同场不允许并发处理，完成后可再次剪辑。
- 手动上传必须每次显式确认，否则服务端强制关闭上传。
