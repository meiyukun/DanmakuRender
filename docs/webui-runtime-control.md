# WebUI 运行控制变更记录

## 背景

`configs/global.yml` 和 Python 代码文件在程序运行中不会自动重新加载。为减少手动停止、启动程序的操作，WebUI 增加运行控制能力，并扩展配置和失败任务管理。

## 新增功能

### 运行控制

- 概况页增加“空闲后重启”。
  - 用户点击后，程序会等待录制、渲染、转录、上传和正在执行的清理任务结束。
  - 未开播的直播监控和未来延迟清理任务不会阻塞重启。
- 概况页增加“强制重启”。
  - 用户点击后，程序不等待任务空闲，直接进入重启流程。
  - 重启前仍会调用现有停止逻辑，让中断任务尽量写入恢复状态。
- 重启使用当前 Python 启动命令原地 `execv`，用于重新加载 `global.yml` 和代码文件。

### 全局配置编辑

- 配置文件管理页现在显示 `configs/global.yml`。
- `global.yml` 可以在 WebUI 中编辑保存，但不允许删除。
- 保存 `global.yml` 后，页面提示需要重启才能生效，并提供：
  - 空闲后重启
  - 强制重启
  - 返回配置列表

### 失败任务批量删除

- 任务页的渲染失败任务支持：
  - 勾选后删除选中
  - 删除全部
- 任务页的上传失败任务支持：
  - 勾选后删除选中
  - 删除全部
- 页面自动刷新时，会保留仍存在失败任务的勾选状态。

## Web API

- `GET /api/restart/status`
- `POST /api/restart/request`
- `POST /api/restart/force`
- `POST /api/restart/cancel`
- `POST /api/failed_renders/delete_batch`
- `POST /api/failed_uploads/delete_batch`

## 实现注意

- WebService 使用可关闭的 threaded Werkzeug server，避免进程内重启后端口仍监听但无法响应。
- 强制重启会中断正在运行的任务，应优先使用“空闲后重启”。
- 失败任务批量删除只删除失败任务记录，不删除已经生成的视频文件。
- 任务页的“流水线恢复状态”展示重启时加载的未完成视频组。这里显示的是流水线状态账本；实际中断的渲染或上传任务仍会进入对应失败任务列表，需按任务状态决定是否重试。
- 不再需要的恢复流水线记录可以在任务页批量删除。仍有处理任务的记录不允许删除，删除记录不会删除视频文件。
- 已结束的视频组如果没有配置后续上传或清理动作，也没有活动请求，会自动从流水线状态账本中清理；启动加载历史状态时同样会执行此判断。
