# 上传素材库分页与筛选

- 上传账号、默认投稿参数和合集配置改由 `/api/upload/options` 独立加载，不再等待左侧素材扫描。
- `/api/upload/library` 改为服务端分页，只返回当前页素材，默认每页24项。
- 支持按录制任务、素材类型和关键词筛选；素材类型包括原始录屏、转码前录屏、弹幕版、热点成片、热点片段及自定义混剪。
- 支持按最后修改时间正序或倒序、按名称正序或倒序排列。
- 素材列表不再逐个调用FFprobe；录屏时长读取流水线记录，热点时长读取热点清单，显著减少首屏等待。
- 素材文件元数据建立15秒短时索引缓存，翻页和调整筛选时不重复扫描磁盘；正式提交上传时强制刷新路径校验。
- 翻页和切换筛选不会清空已选择的分P，已选素材信息保存在浏览器当前页面中。
