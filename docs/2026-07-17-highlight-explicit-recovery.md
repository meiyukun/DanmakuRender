# 热点任务显式恢复与字幕默认策略

## 改动内容

- 程序重启后，热点剪辑 Worker 不再自动执行持久化任务，只在 Web 中明确点击恢复后重新派发。
- 待恢复热点任务无论中断前处于哪个阶段，都可以删除恢复记录；删除不会删除源视频或已经生成的成片。
- 等待空闲重启时不再把尚未选择恢复的热点记录视为运行中任务。
- 忽略已经超时或结束的字幕依赖迟到消息，避免降级分析后再次重复启动剪辑。
- 热点配置和 Web 手动剪辑的默认字幕策略改为 `available`（仅使用已有字幕，不等待生成）。
