# Web 手动热点剪辑输出方案选择

## 改动内容

- 手动热点剪辑不再要求用户输入逗号分隔的输出 ID。
- 页面根据当前录制任务合并后的热点配置，列出所有可用输出方案。
- 除 DMH 已配置方案外，手动页面补充搞笑、帅气操作、逆天、翻车失误和情绪高光标准方案；这些补充不会改变自动剪辑输出。
- 每个选项显示方案名称、内部 ID 和热点类别，默认全部选中，并允许多选。
- `*` 在页面中显示为“全部类别”，避免被误解为只有一个可选 ID。
- DMH 原本配置的方案默认勾选，页面补充的标准分类默认不勾选，避免无意生成或上传多份视频。
- 前端和后端都要求至少选择一个方案；后端拒绝配置中不存在的输出 ID。
