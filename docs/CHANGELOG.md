# Changelog

## Unreleased

### Added

- WebUI 任务页新增流水线恢复状态，显示重启加载的视频组、总体状态和各阶段文件状态。
- WebUI 支持批量删除不再需要、且没有活动任务的重启恢复流水线记录，不删除视频文件。
- WebUI 增加空闲后重启功能，用于在没有活跃任务时重新加载 `configs/global.yml` 和代码文件。
- WebUI 增加强制重启功能，可无视正在运行的任务直接触发重启流程。
- WebUI 配置文件管理支持编辑 `configs/global.yml`，保存后提示重启生效，并提供重启入口。
- WebUI 任务页支持批量删除渲染失败任务和上传失败任务。

### Changed

- 已结束且没有后续上传、清理或活动请求的流水线状态会在运行时和启动加载时自动清理。
- 流水线恢复日志改为“已加载”，明确区分状态账本加载与任务重新执行。
- WebService 改为可关闭的 threaded Werkzeug server，避免进程内重启后端口仍监听但无法响应。

### Notes

- 强制重启会中断正在运行的录制、渲染、上传或清理任务，优先建议使用空闲后重启。
- 失败任务批量删除只删除失败任务记录，不删除已经生成的视频文件。
