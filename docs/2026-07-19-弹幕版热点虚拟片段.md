# 弹幕版热点虚拟片段

## 改动摘要

- 使用 `source.video: dm_video` 的自动和手动热点任务改为保存虚拟时间范围，不再预先生成每个热点小片段文件。
- 热点清单升级为 v3，虚拟片段保存原始范围、当前范围、修订号和跨录像分段的 `pieces`；旧实体清单仍可读取。
- 未开启自动上传时只保存系统推荐列表，素材库可按需生成推荐混剪；开启上传时仍会立即生成成片。
- Web 素材库支持从弹幕版源视频预览热点区间、调整入点和出点，并将已有推荐成片标记为可能过期。
- 自定义混剪可以混合使用虚拟和实体热点素材，虚拟素材仅在输出阶段临时实体化。

## 新增运行期文件

- `.temp/highlight_operations.json`：Web 推荐混剪后台操作状态，不应提交到 Git。
- `.temp/highlight-thumbnails/`：按源文件状态和片段修订号缓存的热点缩略图。

## 兼容说明

- 原编码 `src_video` 继续使用实体裁切，关键帧处理逻辑不变。
- 删除虚拟片段不会删除弹幕版源视频；热点清单引用的源视频不属于热点结果的可删除产物集合。
