# 热点候选素材库与自动成片解耦

## 改动内容

- 本地弹幕算法识别出的全部热点候选都会裁切为独立小片段，不再因为 AI 拒绝而从素材库消失。
- AI 审核结果只决定候选是否有资格进入初始自动混剪；AI 未入选片段仍可在 Web 素材库中预览和人工选择。
- `max_clips` 和 `max_total_duration` 只限制初始自动混剪，不限制独立小片段数量。
- 自动混剪的类别选项只过滤进入自动成片的候选，不再过滤素材库候选。
- 素材清单记录 AI 审核状态、置信度、原因以及是否进入初始自动混剪。
- Web 素材卡新增“已进入自动成片”“AI 未入选”“备选素材”状态标识。
- 修正自动混剪时长选择：超出总时长的候选会跳过，并继续尝试后续较短候选，且单个片段也不会突破总时长上限。

## 清单字段

- `clips`：全部已成功裁切的本地热点候选。
- `selected_candidates`：AI 允许参与自动成片筛选的候选。
- `auto_selected_candidates`：最终受类别、数量和总时长限制后进入初始自动混剪的候选 ID。
- `outputs`：初始自动混剪成片。
- `versions`：用户从素材库人工选择后生成的自定义混剪。
