# 手动热点剪辑复用已上传稿件字幕

## 改动

- 上传器完成B站投稿后，将 BVID、上传引擎、账号和分P标题随完成事件返回。
- 直播流水线把原版或弹幕版视频对应的稿件信息写入 `VideoInfo`，并同步到已完成直播场次目录。
- 手动热点剪辑在本地字幕缺失且字幕策略不是 `disabled` 时，优先把已有稿件信息交给B站字幕引擎。
- B站字幕引擎复用现有稿件查询、分P匹配、中文字幕选择和 SRT 转换逻辑；在限定时间内没有取得字幕时，回退原有字幕代理视频上传流程。
- 稿件元数据随场次持久化并可在程序重启后继续使用，不记录Cookie内容。

## 配置

- `transcribe_args.bilibili.existing_upload_timeout`：尝试已有稿件字幕的最长等待时间，默认300秒。
